# Python-Django-Chat-Application
Usage of Python Channels &amp; Websockets

# Summary
Django Chat Application Developed for learn how can send text messages using Channels & Websockets. 

# Steps to Use
Clone git clone https://github.com/SudhansuShakya/Python-Django-Chat-Application.git

cd Python-Django-Chat-Application

install requirements pip install -r req.txt

python manage.py makemigrations

python manage.py migrate

Runserver Python manage.py runserver
